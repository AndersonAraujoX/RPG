Skill: Building & Maintaining a +2d6 System VTT Web Application

Overview

This skill defines the technical specification, system rules, architectural constraints, and prompt guidelines required to build, update, or expand a serverless, single-file Virtual Tabletop (VTT) web application for the +2d6 RPG System (v2.3 by Newton "Tio Nitro" Rocha) hosted on GitHub Pages.

1. System Rules Core Engine (+2d6 v2.3 Specification)

Any agent generating or modifying code for this application MUST adhere strictly to the following rules:

A. Core Dice Mechanics

Formula: $2d6 + \text{Atributo} + \text{Perícia} + \text{Modificador de Ocasião}$

Normal Test (CD):

Easy: CD $8$

Normal: CD $10$

Hard: CD $14$

Impossible: CD $18+$

Opposed Test: Attacker's total vs. Defender's total (highest wins).

Critical Success: $6 + 6$ on the dice roll (doubles damage or critical outcome).

Critical Failure: $1 + 1$ on the dice roll (fumble, weapon damage, or self-harm).

B. Attributes & Scale

Attributes: Força (FOR), Destreza (DES), Constituição (CON), Inteligência (INT), Sabedoria (SAB), Carisma (CAR), Poder (POD).

Human Scale: Values $1$ to $5$.

Super-Human Scale ($6$ to $10$):

Grants $+6$ flat bonus when tested against human-level attributes.

Divine Scale ($10+$):

Grants $+6$ flat bonus against super-human level.

Grants $+12$ flat bonus against human level.

C. Derived Statistics Formulas

Maximum Hit Points ($PV_{max}$):


$$PV_{max} = 10 + \text{CON} + \text{FOR} + (\text{CON} \ge 3 \implies +5)$$

Maximum Energy Points ($PE_{max}$):


$$PE_{max} = \text{POD} + 10$$

Initiative Bonus:


$$\text{If } \text{DES} \ge 3 \implies \text{Bonus} = \text{DES} - 2$$

Base Strength Damage:

$\text{FOR } 1 \implies 1d6 - 4$

$\text{FOR } 2 \implies 1d6 - 2$

$\text{FOR } 3 \implies 1d6$

$\text{FOR } 4 \implies 1d6 + 1$

$\text{FOR } 5 \implies 1d6 + 2$

$\text{FOR } 6 \implies 3d6$

$\text{FOR } 7 \implies 4d6$

$\text{FOR } 8 \implies 5d6$

$\text{FOR } 9 \implies 6d6$

$\text{FOR } 10 \implies 7d6$

D. Survival & Death Mechanics

Unconsciousness: Triggered when current $PV \le 0$.

Death Test: Rolled each round while $PV \le 0$:

Roll $2d6$:

Result $\ge 6$: Success (remains alive).

Result $< 6$: Failure (accumulates 1 death failure).

Result $= 12$: Immediate Stabilization!

Definitive Death: Accumulating $3$ Failures OR $PV$ drops below $-(CON + FOR)$.

2. Technical & Architectural Mandates

Single-File Mandate

The entire web application MUST be contained in a single index.html file.

All styles MUST use Tailwind CSS via CDN or inline <style>.

All JavaScript MUST be contained within standard <script> tags inside index.html.

Icons MUST use FontAwesome CDN.

Persistence Layer

Local Storage: Save character sheets and state automatically with a 500ms Debounce.

JSON Import/Export: Enable full character sheet backup and sharing via .json files.

Firebase Firestore (Optional/Hybrid): Serverless real-time synchronization for multi-user campaigns.

3. UI/UX Structure & Navigation

The application interface MUST feature a dark theme (slate-900 / emerald-500 palette) divided into 5 main tabs:

Rolador (Dice Roller):

Dropdowns for Attribute, Skill, Occasion Modifier ($-6$ to $+6$), and CD selection.

Immediate feedback box with animations, critical callouts, and timestamped roll history log.

Ficha (Character Sheet):

Dynamic inputs updating derived stats in real time.

Lists for Perícias, Vantagens, Desvantagens, and Inventory.

Combate (Combat Tracker):

Initiative roller ($2d6 + \text{DES} + \text{Iniciativa}$).

Turn tracker, active turn highlight, condition counters, and health controllers.

Monstros / PdMs (NPC Generator & Bestiary):

Generator based on Challenge Rating (ND 0 to ND 10).

Presets from the official manual (Zumbi Capenga, Chefe Goblin, General Orc, Cthulhu, Kratos).

Compêndio (Rules & Magic Grimoire):

Searchable tables for Melee Weapons, Firearms, Armor (RD values), and Spells (Levels 1 to 5).

4. Master Prompt for AI Agents

When instructing an AI to construct or refactor this project, send the following unified master prompt:

Build a complete, single-file Virtual Tabletop (VTT) and digital suite in HTML/JS/Tailwind CSS for the +2d6 RPG System (v2.3 by Newton "Tio Nitro" Rocha).

Key Requirements:
1. Architectural Constraint: Everything must be contained inside a single `index.html` file compatible with GitHub Pages hosting. Use Tailwind CSS CDN and FontAwesome CDN.
2. Rule Engine Implementation:
   - Formula: 2d6 + Attribute + Skill + Modifiers.
   - Calculate criticals: 6+6 (Critical Success), 1+1 (Critical Failure).
   - Dynamic derived stats: PV = 10 + CON + FOR (+5 if CON >= 3), PE = POD + 10, Initiative Bonus = DES - 2 (if DES >= 3), FOR damage mapping.
   - Automated Death Tests when PV <= 0 (2d6 roll: >=6 pass, <6 fail, 12 auto-stabilize, 3 fails = dead).
3. Functional Modules:
   - Dice Roller with animation, modifiers, CD check, and history log.
   - Character Sheet with real-time stat calculations, LocalStorage auto-save, and JSON import/export.
   - Combat Tracker with automated initiative sorting and HP tracking.
   - NPC Generator per ND (0 to 10) with preset monsters from the manual.
   - Rules Compendium with weapons, armor (RD), and spell grimoire (Levels 1-5).
4. Code Quality: Clean Vanilla JS, event-driven architecture, responsive mobile-friendly dark theme design.

[ ] Verify that all mathematical formulas strictly adhere to Section 1.

[ ] Check LocalStorage synchronization after modifying character schema.

[ ] Test JSON export and re-import to guarantee backward compatibility.

[ ] Validate responsive layout on both mobile and desktop screen widths.
